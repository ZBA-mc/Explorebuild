Explorebuild

A Minecraft-style sandbox game implemented in Python, featuring Faithful 64x texture support.

Implemented Features

Movement & Perspective

WASD Movement for smooth first-person navigation and immersive view with mouse look controls.

Terrain Generation

Procedurally generated landscapes for endless exploration with chunk-based map system.

Block Interactions

Multiple block types to collect and place, with left-click placement and right-click destruction.

Game Mechanics

Space jump for parkour-like movement and ESC pause menu for settings or quitting the game.

Block Selection

Switch between block types with number keys, with hand visualization showing the active block.

Performance

Efficient 4×4 chunk (32×32 block) rendering system for optimal performance.

Planned Optimization Targets

Inventory System

Backpack UI for managing collected items and resources.

Player Interactions

Enhanced interactions with objects and the environment.

Mob AI

Intelligent behavior logic for in-game creatures.

Map Generation

Enhanced terrain generation and performance tuning.
